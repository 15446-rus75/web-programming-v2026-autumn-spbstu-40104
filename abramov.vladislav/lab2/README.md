# Лабораторная работа 2

## Задание

Вариант №1. Реализовать функцию analyzieString, которая принимает строку и
возвращает объект с количеством букв, цифр, пробелов и остальных символов.

## Реализация

Функция analyzieString экспортируется как именованный ES module export. Алгоритм
проходит по строке посимвольно через цикл for. Для каждого символа проверяется
категория в порядке приоритета: пробел, цифра, буква, остальное. Результат
возвращается как объект { letters, digits, spaces, other }.

## Запуск

Запуск через Node.js как ES Module.
