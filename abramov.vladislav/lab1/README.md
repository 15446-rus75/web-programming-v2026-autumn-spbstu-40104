# Лабораторная работа 1

## Задание

Вариант №1. Создать форму регистрации: поля «Имя», «E-mail», «Телефон»,
«Пароль», «Пароль еще раз» и кнопка «Регистрация». Форма должна удовлетворять
следующим требованиям: ширина формы — 400px; внутренний отступ — 8px; цвет
кнопки — #0056ff; цвет кнопки при наведении курсора — #417ffb.

## Реализация

Форма собрана на теге <form> с пятью input соответствующих типов (text, email,
tel и два password) и кнопкой отправки. Все стили вынесены в отдельный CSS-файл.

## Запуск

Откройте index.html в браузере или поднимите локальный сервер из папки
