# Лабораторная работа 3

## Задание

Вариант №1. Реализовать функцию removeDuplicates(arr), которая возвращает новый
массив без дубликатов.

## Реализация

Решение использует встроенный Set, который отбрасывает повторные значения, а
порядок итерирования Set по спецификации совпадает с порядком первого добавления
элементов, что даёт требуемый порядок первого появления. Оператор [] создаёт из
Set новый массив, исходный массив при этом не изменяется.

## Запуск

Запуск через Node.js как ES Module.
