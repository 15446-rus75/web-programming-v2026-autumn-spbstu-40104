# Лабораторная работа 5

## Задание

Вариант: Сортировка книг в книжном интернет-магазине.

Создать список книг, каждая карточка содержит: обложку, название, рейтинг,
описание и цену.

Над списком книг размещены кнопки сортировки: «Название», «Цена», «Рейтинг».

## Реализация

Стек: React 18 + Vite.

Структура:

- `src/main.jsx` — точка входа и корневой компонент приложения:
  - массив книг `BOOKS` хранится прямо в модуле (внешние API/CDN не
    используются);
  - состояние сортировки: `sortField` (title / price / rating / null) и
    `sortOrder` (asc / desc / null);
  - клик по кнопке сортировки циклически меняет состояние: сначала по
    возрастанию, затем по убыванию, затем сброс к исходному порядку;
  - карточки книг рендерятся из отсортированной копии массива;
  - обложки книг реализованы как цветные блоки с эмодзи-символом (без загрузки
    изображений из сети).
- `src/styles.css` — стили сетки карточек, обложек и кнопок сортировки (активная
  кнопка выделяется цветом).
- `vite.config.jsx` — конфигурация Vite с плагином React.

Корневой элемент приложения: `<main data-testid="app" id="root"></main>`.

## Запуск

Установка зависимостей: npm install

npm run build npm run dev / npm run preview

Открыть в браузере адрес `http://localhost:5173` / `http://localhost:4173`.
