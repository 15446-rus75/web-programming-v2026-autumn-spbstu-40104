# Лабораторная работа 1

## Задание

Вариант 27. Создать блок с текстом произвольной длины и с помощью CSS ограничить
его отображение высотой 100px или 3 строками: текст, выходящий за пределы
лимита, обрезается и заменяется многоточием (…). Шрифт блока — Arial, размер
шрифта — 16px.

## Реализация

Страница состоит из заголовка, блока статьи с подзаголовком и абзаца с текстом
произвольной длины, который обрезается по высоте или количеству строк.

Для ограничения текста по высоте и количеству видимых строк, отображения
многоточия при обрезке и задания шрифта текста в теге p установлен атрибут class
со значением "clamp-text".

Для обрезки текста по строкам использованы свойства display, -webkit-box-orient
и -webkit-line-clamp, для ограничения по высоте - max-height, для скрытия
лишнего содержимого - overflow, для замены обрезанного текста многоточием -
text-overflow, для шрифта и его размера - font-family и font-size
соответственно.

## Запуск

Откройте `index.html` в браузере.
